## Прямые конкуренты

### 1. Angi (formerly HomeAdvisor + Angie's List)

**App Store:** ⭐ 4.8 · 480K reviews (iOS) | Google Play: 4.5 · 150K+  
**Категория:** Home Services Marketplace  
**Позиционирование:** "Find trusted pros for 50+ home services"

**Монетизация**
- Бесплатно для consumers
- Pros: pay-per-lead + подписка (Angi Ads)
- Consumer membership: $30/год (скидки на услуги)
- HomeAdvisor поглощён Angi (март 2025), единый бренд

**Ключевые фичи**
- Поиск подрядчиков в 50+ категориях
- Verified reviews (10M+)
- Instant booking
- Project tracker
- HomeAdvisor True Cost Guide (web-только, статичные диапазоны по 300+ категориям)
- iOS 26 design refresh (2026)

**Сильные стороны (из отзывов)**
- "Нашёл отличного подрядчика за 20 минут" — простота matching
- Верифицированные лицензии и страховки подрядчиков
- Огромная база отзывов как социальное доказательство
- Бесплатно для пользователя

**Слабые стороны (из отзывов)**
- "Сразу начинают звонить 5 мастеров — надоедает" (Trustpilot 2.1/5, BBB: F)
- Нет реальной цены до звонка подрядчику
- Cost Guide — веб-страница 2008 года дизайна, не мобильная
- Нет photo-input для диагностики
- "Подрядчик не приехал, деньги не вернули" — частые жалобы на сервис

**Threat уровень:** 🟠 MEDIUM — партнёрство через Angi Leads API реалистичнее конкуренции

### 2. Thumbtack

**App Store:** ⭐ 4.89 · 432K reviews (iOS) | Trustpilot: 3.9/5  
**Категория:** Home Services Marketplace  
**Позиционирование:** "Get matched with local pros instantly"

**Монетизация**
- Бесплатно для consumers
- Pros: pay-per-lead ($5–40/lead, растёт)
- Plus membership для pros: $49/год (20% скидки на-demand)
- Instant deposit за сервисную плату: 1%

**Ключевые фичи**
- AI-powered matching (анализирует историю и предпочтения)
- Instant booking с подтверждением
- 50+ категорий, 300K+ pros по всей стране
- In-app payments (Thumbtack Pay)
- Smart lead management

**Сильные стороны (из отзывов)**
- "Быстро нашёл кого нужно, удобное приложение"
- Широкое покрытие городов и категорий
- Высокий App Store рейтинг = доверие
- Pro API (developers.thumbtack.com) — интеграция с партнёрами

**Слабые стороны (из отзывов)**
- "Leads стоят $30 и никто не отвечает — выброшенные деньги" (жалобы pros)
- Нет стоимостной оценки для consumer — цену узнаёшь только после созвона
- Нет photo-input диагностики
- Нет DIY-варианта — только "нанять кого-то"
- Zero-refund политика на некачественные лиды

**Threat уровень:** 🟠 MEDIUM-HIGH — affiliate-партнёр, но может добавить AI фичи

### 3. iFixit (с FixBot AI)

**App Store:** ⭐ 4.8 (iOS, запуск декабрь 2025) | Google Play: аналогично  
**Категория:** DIY Repair Guides + AI Assistant  
**Позиционирование:** "Fix anything with expert step-by-step guides + AI"

**Монетизация**
- **Free:** полный доступ к 125K гайдам + базовый FixBot
- **Premium:** $4.99/мес или $50/год — голосовое управление, загрузка документов (PDF мануалы)
- Исторически: продажа инструментов и запчастей ($50M+ ARR estimate)

**Ключевые фичи**
- 125K+ repair guides (wiki-модель, community-powered)
- **FixBot** — AI-ассистент на базе всей базы знаний iFixit
- Workbench: трекинг текущих ремонтов
- Battery lifespan predictor
- Форум Q&A
- PDF мануалы устройств

**Сильные стороны (из отзывов)**
- "FixBot знает больше, чем любой ремонтник которого я знаю"
- Легендарный бренд доверия (сайт с 2003 года)
- Абсолютно бесплатная база гайдов
- Community-verified информация

**Слабые стороны (из отзывов)**
- **Фокус: электроника и гаджеты, НЕ home repair** (сантехника, стены, HVAC — вне scope)
- Нет оценки стоимости (только цена запчастей)
- Нет matching с подрядчиком
- Нет photo-diagnosis для идентификации проблемы
- "FixBot иногда даёт неверный совет на старое оборудование"

**Threat уровень:** 🟢 LOW — разные домены. Inspiration для brand trust и free-tier контент

### 4. Frontdoor — Home Service Experts

**App Store:** ⭐ ~4.2 (смешанные отзывы) | Google Play: аналогично  
**Категория:** Video Chat с экспертами по ремонту  
**Позиционирование:** "Video chat a home repair expert in minutes"

**Монетизация**
- **Basic (Free):** 1 бесплатный видеочат/год + список местных pros + How-To Tips
- **Prime:** $99/год — 3 видеочата + скидки до 50% + приоритетная запись

**Ключевые фичи**
- Видеочат с лицензированными специалистами (Streem AR-технология)
- Электрика, сантехника, HVAC, бытовая техника, handyman
- Если remote fix невозможен — список проверенных pros
- How-To Tips библиотека
- Принадлежит Frontdoor Inc. (дочка ANGI Holdings, NASDAQ: FTDR)

**Сильные стороны (из отзывов)**
- "Специалист увидел проблему через камеру и объяснил что делать — сэкономил $300"
- Живой эксперт — надёжнее AI для сложных случаев
- AR-технология наглядна

**Слабые стороны (из отзывов)**
- "$99 в год за 3 звонка — дорого для простых вопросов"
- "Эксперт всё равно сказал вызвать мастера — бесполезно"
- Только США
- Структурный bias на escalation (эксперт зарабатывает на "вызвать мастера")
- Нет реальной оценки стоимости

**Threat уровень:** 🟢 LOW-MEDIUM — другой modality, дороже, US-only

- Списки инструментов и материалов

## Косвенные конкуренты

### 8. TaskRabbit (IKEA)

**App Store:** ⭐ 4.8 · 160K reviews (Tasker app iOS)  
**Категория:** Gig Marketplace for Tasks  
**Монетизация:** Platform fee 15% от Tasker earnings + service fee + $25 регистрация tasker

**Почему косвенный:** Бронирует работников, не диагностирует и не оценивает. Overlap только на furniture assembly (IKEA dominant).  
**Сильные:** IKEA partnership, instant booking, same-day, ясные hourly rates, 9 стран.  
**Слабые:** Не для licensed trades (сантехника/электрика/HVAC), нет DIY.  
**Для FixIt:** Канал для Hybrid-output (купи запчасти + закажи установщика через TaskRabbit).

### 9. HomeZada

**App Store:** ⭐ смешанные (complex onboarding, высокий churn)  
**Категория:** Home Asset Management  
**Монетизация:** Free (inventory only) + Premium $99/год + Deluxe (multi-property)

**Почему косвенный:** Proactive maintenance planning, не reactive repair diagnosis.  
**Сильные:** Полный lifecycle управления домом, бюджетирование на годы вперёд, трекинг инвентаря.  
**Слабые:** "Большинство пользователей бросают setup не закончив первую комнату" — UX слишком сложен; нет AI-diagnosis; нет cost estimate для конкретного ремонта.  
**Для FixIt:** Inspiration для feature Home History в v2.0 — хранить историю ремонтов + warranty tracker.

**Почему косвенный:** Design/renovation-focused, не repair. Contractor finder есть, но для проектов ($5K+), не мелкого ремонта.

## GAP-анализ

### Подтверждённый рынком gap (HomeMD.ai independent analysis, 2026)

Три существующих категории AI-инструментов для ремонта — каждая с фундаментальным изъяном:

| Категория | Представитель | Проблема |
|---|---|---|
| **Retail-aligned AI** | Home Depot Magic Apron | Включается ПОСЛЕ решения купить. Не спрашивает "нужно ли вообще это чинить?" |
| **Expert-session AI** | Frontdoor | Структурно biased: эксперту выгодно сказать "вызови мастера" — за это платят |
| **Planning AI** | HomeZada | Проактивное планирование на годы вперёд, не помощь в аварии сейчас |

**Незаполненная ниша:** _"Помоги принять правильное решение за 10 минут, до того как я переплачу."_

Ни один крупный игрок не монетизирует честный triage. Subscription/direct-pay модели не имеют upside от подталкивания к лишним тратам.

### Конкретные gap-ы по фичам

1. **Photo → cost: пропасть.** SnapFix и Fix AI дают photo-input, но cost estimate — поверхностный (без региональной привязки). Angi/HomeWyse дают региональные цены, но только текстом на вебе без AI. **Никто не делает photo → regional AI cost estimate in-app.**

2. **3-mode output: пустое место.** Все конкуренты дают ЛИБО DIY-guide, ЛИБО pro-matching. **Никто не даёт все три варианта side-by-side (DIY / Hybrid / Full Pro) с ценой каждого.**

3. **Neutral advisor: нет.** Thumbtack/Angi зарабатывают когда пользователь нанимает подрядчика → incentive говорить "вызови мастера". iFixit зарабатывает на запчастях → incentive чинить самому. **Первый нейтральный советник = FixIt** (монетизация — подписка, не транзакция).

4. **Global coverage: нет у AI-конкурентов.** SnapFix, Fix AI, YouFixedIt — US-ориентированы без региональной адаптации цен. **FixIt через Claude API — global от старта.**

5. **Furniture + appliance + home в одном: нет.** iFixit = электроника, TaskRabbit = мебель, Angi = trades. **FixIt покрывает все три категории единым UX.**

### Вывод: главный positioning gap

> **FixIt — единственный нейтральный AI-советник с photo-input + региональными ценами + 3-mode output (DIY / Hybrid / Pro) в мобильном приложении.**

Конкуренты либо ведут к подрядчику (Thumbtack/Angi), либо учат чинить (iFixit/YouTube), либо дают стоимость на вебе без AI (HomeWyse). FixIt — первый, кто соединяет всё в одном tap.
