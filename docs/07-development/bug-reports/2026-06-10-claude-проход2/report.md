## Детали

### B01: Ссылка "See a sample estimate instead" открывает чёрный экран с ошибкой

**Где:** Экран Welcome — вторичная ссылка под основной кнопкой (видна при скролле вниз)

**Что вижу:** Нажимаю на ссылку "See a sample estimate instead →" — вместо примера оценки открывается почти пустой чёрный экран. В верхней части мелким белым шрифтом написано: "Failed to load repair template rp-002: TypeError: Network request failed". Больше ничего на экране нет — ни кнопки "назад", ни понятного объяснения.

**Как должно быть:** Ссылка обещает показать пример оценки. Должен открыться заранее подготовленный экран с образцом — с описанием ремонта, ценой и кнопками. Если данные временно недоступны, нужен аккуратный экран с сообщением об ошибке и кнопкой возврата.

**Скриншот:** screenshots/02-sample-estimate-link.png  
**Приоритет:** HIGH

### B02: Кнопка "Upload a saved photo instead" ведёт на экран камеры, а не сразу в галерею

**Где:** Экран Camera Primer — вторичная ссылка под основной кнопкой

**Что вижу:** Нажимаю "Upload a saved photo instead" — открывается экран камеры (с кнопкой затвора, кнопками GALLERY и TEXT). Ожидал, что сразу откроется галерея для выбора уже готового фото. Вместо этого мне нужно ещё раз нажать GALLERY на следующем экране.

**Как должно быть:** Если пользователь явно нажал "загрузить готовое фото", приложение должно сразу открывать галерею — без промежуточного экрана камеры. Лишний шаг вводит в заблуждение.

**Скриншот:** screenshots/04-upload-photo.png, screenshots/05-capture-screen.png  
**Приоритет:** MEDIUM

### B03: Кнопка TEXT на экране Capture открывает галерею вместо поля ввода текста

**Где:** Экран Capture — нижняя часть экрана, кнопка TEXT справа от кнопки GALLERY

**Что вижу:** Нажимаю кнопку TEXT — открывается галерея телефона (выбор фото), а не поле ввода текстового описания. Кнопка GALLERY и кнопка TEXT ведут на одно и то же — выбор фото из галереи. Никакой возможности описать проблему текстом нет совсем.

**Как должно быть:** Кнопка TEXT должна открывать поле ввода, где пользователь может написать текстовое описание проблемы. Сейчас функция "описать текстом" не работает вообще — кнопка существует, но обещанного действия нет.

**Скриншот:** screenshots/05-capture-screen.png, screenshots/05b-text-button-result.png  
**Приоритет:** HIGH

### B04: Поле ZIP на экране Context блокирует продолжение если Location была пропущена

**Где:** Экран Context (шаг 5) — поле ZIP CODE внизу экрана

**Что вижу:** На экране Location нажимаю "Use national average instead" (пропускаю ввод адреса). Иду дальше — на экране Context вижу поле ZIP CODE, которое требует ввода ZIP-кода. Кнопка Continue остаётся неактивной, пока поле пустое. То есть, даже выбрав "использовать среднее по стране" на предыдущем шаге, ZIP всё равно нужен на этом шаге — выбор на Location-экране ни на что не повлиял.

**Как должно быть:** Если пользователь на экране Location выбрал "использовать национальный средний показатель", приложение должно либо не показывать поле ZIP на экране Context, либо делать его необязательным. Решение пользователя должно помниться и применяться последовательно.

**Скриншот:** screenshots/06b-context-zip-validation.png  
**Приоритет:** MEDIUM

### B05: Экран Sign Up показывает технический тег "SUPABASE AUTH"

**Где:** Экран Sign Up ("UNLOCK YOUR REPAIR VAULT") — мелкая строка над заголовком

**Что вижу:** Открываю экран создания аккаунта. Над большим заголовком "UNLOCK YOUR REPAIR VAULT" есть строчка мелким шрифтом: "STEP · CREATE · SUPABASE AUTH". "Supabase" — это название внутреннего технического сервиса, который используется в разработке. Пользователь это название не знает и не должен видеть.

**Как должно быть:** Строка-метка должна либо не упоминать названия внутренних сервисов, либо не отображаться в продакшн-версии вообще. Пользователю достаточно видеть заголовок и описание экрана.

**Скриншот:** screenshots/08-signup-screen.png  
**Приоритет:** MEDIUM

---

### B06: Экран Sign In показывает технический тег "SUPABASE AUTH"

**Где:** Экран Sign In ("WELCOME BACK") — мелкая строка над заголовком

**Что вижу:** Открываю экран входа в аккаунт. Над заголовком "WELCOME BACK" есть строчка мелким шрифтом: "STEP · RETURN · SUPABASE AUTH". Та же проблема, что и на Sign Up — название внутреннего сервиса видно пользователю.

**Как должно быть:** Аналогично B05 — технические названия внутренней инфраструктуры не должны отображаться на экранах для пользователей.

**Скриншот:** screenshots/09-signin-screen.png  
**Приоритет:** MEDIUM
