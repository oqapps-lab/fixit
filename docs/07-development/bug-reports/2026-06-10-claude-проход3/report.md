### П1-B02 ⚠️ НЕ УДАЛОСЬ ПРОВЕРИТЬ — "Check Supabase" на экране ANALYSIS FAILED

**Почему:** Экран ANALYSIS FAILED появляется только после полного прохода Capture → Processing → ошибка API. В Stage 6 (без реального Supabase) этот путь заблокирован — приложение не может загрузить фото. Для воспроизведения нужны реальные ключи Supabase.  
**Вывод:** Баг остаётся записанным из Прохода 1 с оригинальным скриншотом.

### П2-B02 ✅ ПОДТВЕРЖДЁН — "Upload a saved photo" ведёт на камеру, а не в галерею

**Как проверял:** Проверка кода camera-primer.js (строка 86).  
**Результат:** Обе кнопки на экране Camera Primer ("Allow camera" и "Upload a saved photo instead") выполняют один и тот же код — `router.push('/(onboarding)/capture')`. Нет никакого пути, который открывал бы галерею напрямую.  
**Доказательство в коде:** `src/app/(onboarding)/camera-primer.js:86`
